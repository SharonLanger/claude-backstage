# M1 — Example Milestone

## Goal

Demonstrate the basic iteration loop: write tests, run them against the skill, reason about failures, fix, and re-test.

## Scope

- Test the skill's core functionality with 2 representative scenarios
- A single-phase execution (test-01) and a multi-phase execution (test-02)

## Success Criteria

- All tests pass (all assertions green)
- No regressions from previous fixes

## Status

- [ ] Tests approved by the Director
- [ ] All tests passing
- [ ] Review completed
- [ ] Director approves milestone progression
