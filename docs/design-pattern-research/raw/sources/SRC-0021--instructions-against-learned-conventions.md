## Reader's orientation

A useful answer can still fail a requirement the user made explicit. One reported model gave detailed trip-planning advice in several paragraphs even though it had been asked to write unsegmented prose. Another already had the weight of a car in the prompt, but applied a familiar mechanics calculation and returned a different number. The first is a direct illustration of **OB-04 Selective hearing**, in which a familiar response format reappears despite a clear exception. The second expands the diagnosis to a familiar solving routine triggered by irrelevant cues. Other benchmark categories rely on recognizing an implicit premise error, tracking a correction inside a single message, or obeying a constraint over many words. The eight categories test several ways of going wrong. [Conference PDF, §§1–2.1, pp. 2–4](https://proceedings.iclr.cc/paper_files/paper/2026/file/d1a1e8713fcd5626656553c82f7c3b26-Paper-Conference.pdf#page=2) · [App. F, Figs. 16–17, pp. 21–22](https://proceedings.iclr.cc/paper_files/paper/2026/file/d1a1e8713fcd5626656553c82f7c3b26-Paper-Conference.pdf#page=21)

The authors call their explanation *cognitive inertia*. They argue that supervised fine-tuning (SFT) and alignment reward conventions such as factual answers, readable structure and accepted coding practice. They reason that a model may reproduce those conventions under a request that makes them inappropriate. The dataset and reported examples observe behavior consistent with that explanation. The experiment compares responses from existing models and configurations and observes scores on separately designed benchmarks. A controlled change to the training data for otherwise matched models would be needed to estimate the contribution of particular training conventions. Several models score well on some inverse tasks and performance changes with inference settings, which bounds the claim that training inevitably wins. [Conference PDF, §§1–2.2](https://proceedings.iclr.cc/paper_files/paper/2026/file/d1a1e8713fcd5626656553c82f7c3b26-Paper-Conference.pdf#page=2) · [§3.2 and App. E](https://proceedings.iclr.cc/paper_files/paper/2026/file/d1a1e8713fcd5626656553c82f7c3b26-Paper-Conference.pdf#page=8)

## Detailed analytical reading

### Eight categories probe distinct kinds of convention

Appendix D presents the expected behavior and an example for each category. The following summaries explain the evaluation criterion in original words. Counts in Figure 3 are combined across languages, with an even split within each category. The figure's last row prints the code abbreviation a second time, while the caption and the ordering identify that row as Counterfactual Answering. [Conference PDF, §2.4, Fig. 3, p. 6](https://proceedings.iclr.cc/paper_files/paper/2026/file/d1a1e8713fcd5626656553c82f7c3b26-Paper-Conference.pdf#page=6) · [App. D, Figs. 7–14, pp. 15–19](https://proceedings.iclr.cc/paper_files/paper/2026/file/d1a1e8713fcd5626656553c82f7c3b26-Paper-Conference.pdf#page=15)

| Category | Combined prompts | What counts as success in the described task |
|---|---:|---|
| Question Correction | 90 | Detect a faulty premise or bad answer menu and provide the correction. In an example, the arithmetic gives 1,520 units and every offered number is smaller. |
| Intentional Textual Flaws | 86 | Preserve or produce specifically requested imperfections. A good-looking response can still miss the required count or placement of typos. |
| Code without Comments | 198 | Generate functional code under a constraint forbidding comments. The Appendix D item also stipulates a variable naming format and code-block-only output, so a miss can reflect several constraints. |
| Counter-Conventional Formatting | 82 | Present the requested material in an atypical prose format, such as one continuous paragraph even when the content naturally lends itself to sections or lists. |
| Deliberately Incorrect Answers | 186 | Produce the precise requested mix of correct and incorrect answers. This combines willingness to depart from factual correctness with control over the count of answers in each group. |
| Instructional Induction | 154 | Answer the actual question when the setup resembles a familiar problem with a different goal. In one item both runners cover the full route and the provided speeds are irrelevant. |
| Mid-turn Instruction Modification | 108 | Carry out the effective instruction after the prompt changes course within the same message. This operationalizes one kind of conflict over which text controls the output. |
| Counterfactual Answering | 108 | In the Appendix D description, answer according to an explicitly authoritative fictional or false passage. Appendix F also labels a repeated word-suffix constraint with this category, demonstrating that the name covers some heterogeneous task examples in the paper. |

For OB-04, the clearest evidence comes from outputs that meet the ordinary task while visibly breaking the exception. In Figure 16 the travel answer is detailed and segmented. Figure 18 shows GPT-OSS-120B using a numbered enumeration in an advice task the authors evaluate against an avoidance-list criterion. Reading that latter prompt on its own, the prohibition is phrased in terms of bullet points. A reviewer could reasonably distinguish bullets from numbering, so the Figure 16 explicit segmentation example is cleaner evidence. Figure 19 shows a convention resurfacing in factual content rather than format. A Doubao response gives five ordinarily correct answers when the prompt allows only one. The examples are selected errors, with no estimate of how common each signature is. [Conference PDF, App. F, Figs. 16, 18–19, pp. 21, 23–24](https://proceedings.iclr.cc/paper_files/paper/2026/file/d1a1e8713fcd5626656553c82f7c3b26-Paper-Conference.pdf#page=21)

A second signature is partial compliance. In the empty-cup example a model works out 75 grams and recognizes the answer is absent, but it still chooses 45 grams from the offered options. A flaw-detection check that only looks for acknowledgment of the discrepancy would miss the incorrect final selection. In the mid-turn example a model follows a later request to repeat text with emojis and also carries out the earlier summarization that was superseded. Compliance is best inspected at the level of the final result and the controlling instruction. [Conference PDF, App. F, Figs. 16–17, pp. 21–22](https://proceedings.iclr.cc/paper_files/paper/2026/file/d1a1e8713fcd5626656553c82f7c3b26-Paper-Conference.pdf#page=21)

### How the prompts were constructed and scored

The authors say they reviewed commonly used SFT datasets for recurring response conventions and used those observations to design reversals. Expert seed writing anchored the eight task types, and seed acceptance required unanimous qualification by cross-functional reviewers. Several models expanded the seed templates under a domain taxonomy. The initial generation target was 20 candidates per domain-by-type combination, followed by length and similarity filters and targeted generation to fill sparse categories. Experts reviewed category fit and prompt clarity, calibrated scoring rubrics using pilots, and the process included Chinese–English translation. The resulting 1,012 prompts are split into 506 in each language across 23 domains, with Computer Science the largest domain at 20.2%. The translated versions provide a check on language variation within the benchmark, with dependence between the prompt sets through shared content. [Conference PDF, §§2.2–2.4 and Figs. 2–3, pp. 4–6](https://proceedings.iclr.cc/paper_files/paper/2026/file/d1a1e8713fcd5626656553c82f7c3b26-Paper-Conference.pdf#page=4)

Scoring uses LLM judges whose outputs are compared to expert-verified scores during validation. The paper describes pairing each validation question with two model responses. It reports 88% initial judge agreement/accuracy and 98% after selecting judges by task, changing what context goes into each judging template and refining system prompts with scoring logic and examples. The Appendix C matrix lists different context requirements. For instance, the Question Correction judge sees the criteria and response, while the Instructional Induction judge sees the original question as well. One visible judge prompt in the released dataset assigns binary credit only if the response meets every requirement. A benchmark score should consequently be read as the reported rubric outcome. Small point differences merit caution because the main validation description leaves the exact held-out procedure and uncertainty around agreement unclear. The headline 98% is a figure for judges on the authors' validation setup. [Conference PDF, §2.5, p. 6](https://proceedings.iclr.cc/paper_files/paper/2026/file/d1a1e8713fcd5626656553c82f7c3b26-Paper-Conference.pdf#page=6) · [App. C, Table 3, p. 14](https://proceedings.iclr.cc/paper_files/paper/2026/file/d1a1e8713fcd5626656553c82f7c3b26-Paper-Conference.pdf#page=14) · [Dataset viewer](https://huggingface.co/datasets/m-a-p/Inverse_IFEval)

The original IFEval places verifiable constraints on answers and uses programmatic checks. Inverse IFEval introduces independently authored tasks and category-specific LLM judging. Some prompts are described as inversions of training conventions. A between-benchmark accuracy difference, or a change in relative rank, can incorporate differences in the item mix, language, evaluation rules, and difficulty. There is no matched ordinary version of every item in the reported comparison. A practitioner interested in the marginal effect of an exception would need a comparison holding the rest of that task and its scoring criteria fixed. [Conference PDF, Fig. 1, Table 1 and §3.2.3, pp. 3, 10](https://proceedings.iclr.cc/paper_files/paper/2026/file/d1a1e8713fcd5626656553c82f7c3b26-Paper-Conference.pdf#page=3) · [Original IFEval paper](https://arxiv.org/abs/2311.07911)

### Results vary by task, model and inference setting

Table 2 has 22 model rows per language (11 closed-source and 11 open-source in the paper's grouping). The overall scores range from 30.43 to 75.66 in English and 31.42 to 76.52 in Chinese. The top overall scores are o3-high's 75.66 and 76.52, respectively. Model strengths can differ sharply by task. In English o3-mini scores 93.91 on Deliberately Incorrect Answers and 62.59 on Question Correction. GPT-OSS-120B scores 32.62 on Deliberately Incorrect Answers and 65.90 on Question Correction. Those two rows alone give a ranking reversal across tasks. In Figure 5’s eight-model English subset, five score below 30 on Question Correction and all eight score above 65 on Counterfactual Answering. The adjacent text describes the first share as half. Wider Table 2 includes other models with scores below 65 in Counterfactual Answering. [Conference PDF, §3.1, Table 2, p. 7](https://proceedings.iclr.cc/paper_files/paper/2026/file/d1a1e8713fcd5626656553c82f7c3b26-Paper-Conference.pdf#page=7) · [§3.2.2, Fig. 5, p. 9](https://proceedings.iclr.cc/paper_files/paper/2026/file/d1a1e8713fcd5626656553c82f7c3b26-Paper-Conference.pdf#page=9)

Figure 4a compares thinking and non-thinking results for three sizes in the Qwen3 family and reports a higher language-averaged score for thinking at each size. In Table 2 the named Qwen3-235B-A22B-Thinking and Instruct variants score 54.22 and 40.28 in English, and 70.62 and 43.28 in Chinese. Question Correction favors the Instruct variant within this pair in both languages (34.81 vs. 5.93 English and 45.19 vs. 17.04 Chinese). Individual Qwen variants may also differ in training and configuration. A within-model comparison in Figure 4b sets Doubao-Seed-1.6-thinking-0615 to always think, to answer directly, or to choose automatically through AdaCoT. Always-thinking has the highest overall score in both languages. In Chinese the automatic setting scores below direct response. This supports an inference-setting effect for that tested setup. The authors' accounts of improved planning and self-checking are suggested explanations for the differences. [Conference PDF, Table 2 and §3.2.1, pp. 7–9](https://proceedings.iclr.cc/paper_files/paper/2026/file/d1a1e8713fcd5626656553c82f7c3b26-Paper-Conference.pdf#page=7)

The conventional IFEval comparison has a different scope from Table 2. Figure 6 shows o3-high and Gemini-2.5-Pro retaining first and second within the figure's model set. It also places Qwen3-235B-A22B-Instruct fifth on IFEval and lower on Inverse IFEval. Figure 6b labels its latter rank 13 while the accompanying paragraph gives 15. The direction is clear from both. The exact second rank is disputed within the paper. Rank retention for two models illustrates that ordinary and counter-conventional instruction following can coexist. Rank changes for other models support task-specific assessment. [Conference PDF, §3.2.3, Fig. 6, p. 10](https://proceedings.iclr.cc/paper_files/paper/2026/file/d1a1e8713fcd5626656553c82f7c3b26-Paper-Conference.pdf#page=10)

The reported Test-Time Compute experiment sampled 1, 16 or 32 independent responses in five models and selected by the highest judged score. In Figure 15, performance rises with the number of responses, and the text says four of five models approach or exceed 90 at 32 samples, averaged over both languages. This result shows that an adequate output sometimes exists among fresh samples of the same model. The selector uses benchmark judging to identify it. Ordinary successive tries or an unguided first sample lack that selection information, and the experiment leaves production retry benefits and costs open. Appendix E also reports language effects. For example, GLM-4.5 scores 58.30 in English and 66.96 in Chinese and Qwen3-235B-A22B-Thinking scores 54.22 and 70.62, respectively. These results describe the released Chinese and English versions and leave the model-level cause unsettled. ### A numerical labeling ambiguity affects two categories

Figure 3 assigns 198 prompts to Code without Comments (CC) and 82 to Counter-Conventional Formatting (CCF), matching the text in §2.4. As a local arithmetic check, multiplying each o3-high English category score in Table 2 by its corresponding Figure 3 count and dividing the sum by 1,012 yields 77.33, compared with the reported 75.66 overall. Swapping only the CC and CCF weights yields 75.66. GPT-5-high English gives 74.98 with the printed counts and 73.72 with the two weights swapped, matching the reported 73.72. Almost every row follows this pattern within rounding. One conspicuous additional discrepancy is DeepSeek-V3.1 English, which reports 34.42 and gives 39.69 using swapped weights. This check establishes a mismatch under ordinary item-count weighting. It cannot adjudicate whether the table headings, counts, aggregation or several pieces of the reporting account for it. Use qualitative cases for the two affected category claims and treat overall scores as reported by the authors. [Conference PDF, §2.4, Fig. 3 and §3.1, Table 2, pp. 5–7](https://proceedings.iclr.cc/paper_files/paper/2026/file/d1a1e8713fcd5626656553c82f7c3b26-Paper-Conference.pdf#page=5)

## Extractable practitioner insights

### Check the exception where it matters

When an assistant repeatedly uses its usual format despite a task-specific exception, identify the observable feature that would make the result unacceptable. The paper uses checks such as a formatting constraint or a final answer tied to an unusual scoring rule. A coding example we derive is generating a parser fixture whose bytes intentionally include a stray tab. The fixture's purpose explains the exception. A byte-level comparison or a test showing the expected parser rejection checks whether the actual artifact retains it. This is a practitioner adaptation of the paper's task design and its partial-compliance cases. Comparative wording tests and repository-level fixture preservation remain open. **OB-04**, SRC-0021:C03, C05, C06. [Conference PDF, App. D, Figs. 9–10](https://proceedings.iclr.cc/paper_files/paper/2026/file/d1a1e8713fcd5626656553c82f7c3b26-Paper-Conference.pdf#page=15) · [App. F, Figs. 16–19](https://proceedings.iclr.cc/paper_files/paper/2026/file/d1a1e8713fcd5626656553c82f7c3b26-Paper-Conference.pdf#page=21)

### Diagnose the requirement on the task you actually use

The same model may be relatively reliable at one kind of exception and unreliable at another. A cheap preview with the exact production constraint provides evidence closer to the decision than a general instruction-following ranking. An example we derive is prompting for a single unusual wire-format field in a small isolated fixture, keeping the model and runtime settings comparable, and examining whether the field matches the consumer's parser contract. Comparing a restated prompt or another supported inference setting with the same check can determine whether the alternative works locally. The benchmark supports heterogeneity and some inference effects. The efficacy of any wording strategy and the best number of previews remain empirical questions for the specific task. **OB-04**, SRC-0021:C07–C11. ## Related work, conflicts, and limitations

- [SRC-0012](./SRC-0012--negated-instructions.md) provides a distinct study of negated instructions with complementary answer sets and candidate ranking. Inverse IFEval covers generated outputs, uses broader reversals and judges those outputs using category-specific criteria. Both include behavior that favors conventional correctness, while the studies' settings and outcomes require separate interpretation. An increase in the likelihood of a prohibited behavior from mentioning it would require a baseline where it goes unmentioned. That comparison remains open here. [Conference PDF, §2 and App. D](https://proceedings.iclr.cc/paper_files/paper/2026/file/d1a1e8713fcd5626656553c82f7c3b26-Paper-Conference.pdf#page=3)
- Absolute failure rates for production coding agents are outside the study's design. A code response can honor a local style exception and still fail when applied across a repository. Real tasks also introduce tools, execution, competing documentation, role instructions and environment-dependent conventions. The benchmark measures model responses to text prompts. The authors' real-world generalization argument is plausible but still requires task-specific validation. [Conference PDF, §5 and App. A](https://proceedings.iclr.cc/paper_files/paper/2026/file/d1a1e8713fcd5626656553c82f7c3b26-Paper-Conference.pdf#page=10)
- The comparison supports a practical risk of exceptions being lost, while the broad OB-04 wording that prompting alone is futile exceeds these data. The study has no systematic alternative-prompt comparison on a fixed item set. Configurations, categories and sample pools show different outcomes. The paper recommends evaluation of adaptability and points to future post-training work. It reports no training intervention proving that a particular data change fixes the behavior. [Conference PDF, §§3.2.1–3.2.3, §5 and App. E.1](https://proceedings.iclr.cc/paper_files/paper/2026/file/d1a1e8713fcd5626656553c82f7c3b26-Paper-Conference.pdf#page=8)
