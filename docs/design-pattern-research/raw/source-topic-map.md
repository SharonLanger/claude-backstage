## Evidence provenance

Source notes distinguish independent measurements from overlapping HumanEval tasks, alternate versions of one publication, vendor practices and practitioner examples. PAT-0001’s bounded retry result does not measure the effect of resetting a repository chat. PAT-0002’s automated documentation retrieval measures API call validity rather than the success rate of the manual check.

The topic notes specify the independent unit of evidence. Samman and Lexler share the ROSE author and example. The two Pocock articles describe different practices from the same practitioner. Two METR productivity updates share authors and some participants. The duration and shortcut papers share part of an evaluation program. A conference paper and its preprint, a university interview and its republication, and a paper and its own notebook each contribute a single original research account. Changed wording, selection, budget or version can change what counts as comparable evidence.

The pull-request size audit compared the published report with the authors’ tagged notebooks. It retained pooled commit and cumulative line-change comparisons for selected merged PRs, flagged asymmetric file metrics and excluded uncertain named-agent plot rankings. The topic and pattern links include diagnostic and supporting routes. A link alone does not indicate a tested remedy. The topic tables give relationship and strength.

All eight catalog methods use Anthropic’s Claude Code guide for at least one step. Independent empirical papers, policy, or practitioner publications support different parts of each method. The shared guide is one vendor perspective across the catalog. A next practitioner comparison is Simon Willison’s first-person account of asking for options and starting over. Laban et al.’s multi-turn study could narrow the gap between single-prompt position tests and conversation-level loss. Both remain scouting candidates. Neither validates the current patterns.
