# onboarding/

Entry point for developers new to agent systems. Start here before reading any pattern or family documentation.

```
onboarding/
├── README.md           ← this file
├── new-to-agents.md    ← curated reading path; starts with the 3 families every system needs
└── mental-models.md    ← core concepts before reading any pattern
```

## File descriptions

- **new-to-agents.md** — Curated reading path for developers new to agent systems; starts with the 3 families every system needs
- **mental-models.md** — Core concepts to understand before reading any pattern (what agents are, how orchestration works, why patterns matter)

## When to use this folder

Use this folder if you are new to agent systems or onboarding a team member. It provides the minimum conceptual foundation needed before the rest of the catalog makes sense. Skip it if you already have hands-on agent experience.

## How to navigate

| Arrival scenario | Go to |
|---|---|
| "I've never built an agent — where do I start?" | `mental-models.md` first, then `new-to-agents.md` |
| "I know what agents are but want a guided reading order" | `new-to-agents.md` |
| "What are the core concepts I need before reading patterns?" | `mental-models.md` |
