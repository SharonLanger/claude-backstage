# Contributing

Guides for adding to the AI/Agent Design Patterns catalog.

```
contributing/
├── README.md                  ← this file
├── catalog-intake.md          ← full pipeline: blog → catalog entries (start here)
├── authoring-guide.md         ← writing spec: schemas for patterns, anti-patterns, principles, guides, use-cases
├── classification-guide.md    ← how to classify content and assign to a family
└── source-registry.md         ← verified URLs, citation rules, family–source mapping
```

## Which file do I read?

| I want to… | Read this |
|---|---|
| Add patterns from a new blog/article | [catalog-intake.md](catalog-intake.md) — start here, it routes to the others |
| Write a pattern, anti-pattern, principle, guide, or use-case file | [authoring-guide.md](authoring-guide.md) |
| Decide which family a pattern belongs to | [classification-guide.md](classification-guide.md) |
| Cite a source or add a new one to the registry | [source-registry.md](source-registry.md) |
| Find existing patterns (to check for duplicates) | [../catalog-lookup.md](../catalog-lookup.md) |
